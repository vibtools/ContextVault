# Version Label Correction: 1.0.0

No public ContextVault `v1.0.0` release is represented by the current public release history.

An earlier documentation draft used `1.0.0` in several files while the public tag line was `v0.1.0`. This page is retained so old links do not fail and to make the correction explicit.

Use:

- [v0.1.0 — Initial public release](0.1.0.md)
- [v0.2.0 — Export reliability and stability](0.2.0.md)

The archive schema version remains `1.0`. That schema number is not the application release number.
