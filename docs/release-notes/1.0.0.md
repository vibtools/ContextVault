# ContextVault 1.0.0

ContextVault 1.0.0 implements the frozen Windows desktop architecture: CustomTkinter UI, managed task queue, dedicated Playwright browser lane, persistent Chrome/CDP integration, lossless parser, complete archive generation, deterministic summaries/search indexes, RAG documents, integrity validation, history, settings, logging, tests, Nuitka OneDir build automation, and GitHub Actions packaging.

Known release-validation requirement: official binaries must pass the repository Windows CI workflow and a clean Windows 10/11 Google Chrome runtime smoke test before publication.

## Release certification

The source release candidate passes 39 automated tests. Stable publication remains blocked pending the official Windows x64 build, real Chrome-profile smoke test, clean-machine portability/DLL inspection, performance validation, GitHub Actions run, and release-tag verification. See the [release validation matrix](../developer/release-validation.md).
