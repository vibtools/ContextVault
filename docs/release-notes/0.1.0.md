# ContextVault v0.1.0

**Release date:** 2026-07-28
**Type:** Initial public release

ContextVault v0.1.0 introduced the first public Windows desktop release for exporting ChatGPT conversations into validated local archives.

## Highlights

- CustomTkinter desktop interface.
- Google Chrome Stable automation through Playwright.
- Separate persistent ContextVault Chrome profile.
- Conversation sidebar scanning.
- Message parsing for text, Markdown, HTML, code, images, tables, attachments, and citations.
- Portable archive folder with metadata, RAG files, search index, statistics, logs, and SHA-256 hashes.
- Archive validation and management.
- Settings, export history, logs, tasks, cancellation, and notifications.
- Nuitka OneDir build and GitHub Actions workflows.
- MIT license and public source.

## Known limitations

The initial release had reliability gaps that became visible during large and asset-heavy exports:

- a fixed readiness deadline could stop a progressing large export;
- a stalled browser image could block scrolling;
- decorative image routing could trigger attachment fallback;
- duplicate export submissions could interleave;
- archive publication could collide;
- some public version labels incorrectly stated `1.0.0`.

These issues are addressed in [v0.2.0](https://github.com/vibtools/ContextVault/blob/main/docs/release-notes/0.2.0.md).

## Upgrade recommendation

Users of v0.1.0 should upgrade to v0.2.0 for export reliability and documentation corrections.

Read [Upgrading](https://github.com/vibtools/ContextVault/blob/main/docs/getting-started/upgrading.md).
