ContextVault 1.0.0
==================

ContextVault preserves ChatGPT conversations as portable, lossless, RAG-ready archives.

Requirements
------------
- Windows 10 or Windows 11 (64-bit)
- Google Chrome Stable
- An existing ChatGPT login in the selected Chrome profile

Portable release
----------------
1. Extract the complete ContextVault-Windows-x64.zip archive.
2. Run ContextVault.exe from the extracted folder.
3. Configure the Chrome profile and export destination in Settings.
4. Launch or connect to Chrome, scan conversations, select conversations, and export.

ContextVault does not bundle Chromium and does not collect credentials.
