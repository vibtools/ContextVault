# Overview

ContextVault is an open-source desktop application designed to capture, organize, manage, and export AI conversations into a structured archive.

The project focuses on reliability, maintainability, and long-term portability while following a specification-driven engineering process.

---

# Key Features

* Modern desktop application
* CustomTkinter user interface
* Playwright-powered browser automation
* Structured archive generation
* Project manifest support (`vibproject.ygit`)
* Portable OneDir distribution
* GitHub Actions build pipeline
* Production-oriented architecture
* Thread-safe implementation
* AI-assisted development workflow

---

# Project Goals

* Preserve AI conversations in a structured format
* Maintain long-term archive compatibility
* Provide deterministic project behavior
* Support reproducible builds
* Enable maintainable open-source development

# Development

Clone the repository:

```bash
git clone https://github.com/vibtools/ContextVault.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application (development):

```bash
run.bat
```
